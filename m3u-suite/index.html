// how it fits together

From playlist to picture

  1. Curate in m3u editor

    Import playlists and EPG sources, organize channels and series, and expose a clean Xtream-compatible API — one container to start, or split services for more control.

  2. Deliver through m3u proxy

    Pair the editor with m3u proxy (plus Redis) for restreaming, failover, and hardware-accelerated transcoding when clients need a different format.

  3. Watch with m3u tv — or anything else

    Use the suite's own TV app, or point any Xtream-compatible client at your server. Your setup, your choice.

Get started in minutes

Everything ships as Docker images with step-by-step guides at m3ue.sparkison.dev. Questions or feature ideas? The issue tracker is active and answered.

// faq

Suite questions

What is m3u editor?

A free, self-hosted IPTV playlist manager. It imports m3u, m3u8, m3u+ playlists and Xtream codes APIs, manages EPG data from XMLTV files, URLs, or Schedules Direct, outputs an Xtream-compatible API, syncs .strm files for media servers, and automates post-processing with scripts, webhooks, and email — features comparable to xteve or threadfin, and more.

Is the m3u suite free?

Yes. All three applications — m3u editor, m3u proxy, and m3u tv — are open source and free to use. Source code, releases, and issue trackers are on GitHub.

How do I install it?

With Docker. Run m3u editor as a single container to start, or run separate m3u editor, m3u proxy, and Redis containers for more control and hardware-accelerated transcoding. Step-by-step guides live at m3ue.sparkison.dev.

What platforms does m3u tv support?

m3u tv is built with Flutter and runs on iOS, Apple TV, Android, Android TV, macOS, Linux, and Windows. See screenshots, downloads, and app store links →.
